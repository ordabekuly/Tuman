# UI reference and provenance

- [Kenney UI Pack — creator page](https://kenney-assets.itch.io/ui-pack): free/name-your-price pack; CC0 1.0 Universal. Consulted 19 November 2026 for UI hierarchy and reusable panel/button/control vocabulary.
- [CC0 license](https://creativecommons.org/publicdomain/zero/1.0/).

No paid reference or paid asset was downloaded. No Kenney images are redistributed. Tuman's interface uses native Unity UI rectangles, borders, text and the pre-existing generated village background, with a dusk teal/gold treatment. The home screen uses an asymmetric title and journal card; level selection uses three cards; settings uses sliders and a separate reset area; pause/result use focused overlays.

The original user-provided art remains in the project. Generated animation source sheets are stored locally in Assets/Art/Animations; the project does not rely on expiring external image URLs.
