# Task 11 — тапсыруға дайындық

## Unity-де ашу

1. `Assets/Scenes/Tuman11.unity` сценасын ашып, Play бас.
2. Home → Courtyards: басында тек бірінші деңгей ашық.
3. Joystick/WASD арқылы жүр; FIRE-ды ұстап немесе Space басып ат.
4. Барлық жауды жеңсең, келесі деңгей ашылады. Қызыл көзді қасқыр адамға үш оқ керек.
5. Settings арқылы Ambience және Effects дыбысын өзгерт. Reset Progress растау терезесін ашады.

## Нені түсіндіру керек

- PlayerStats — ойыншының параметрлері; Werewolf_* — жаудың параметрлері; ItemValues — ұпай мен емделу мәндері.
- Level_01/02/03 — бір карта коды оқитын үш дерек жиынтығы. Жаулардың саны, орындары, уақыт пен атмосферасы өзгереді.
- GameSession — деңгей мен прогресс; SaveService — JSON оқу/жазу/тексеру; GameUI — экрандар; PlayerSpriteAnimation — қозғалыс пен ату анимациялары.
- Save файлы жоқ немесе бұзылған болса, ойын бастапқы мәндермен ашылады.
- Сақтау деңгей аяқталғанда, баптау өзгергенде, қолданба фонға кеткенде және жабылғанда орындалады.

## Өзің жасайтын дәлелдер

1. Телефонға APK орнат. Бірінші деңгейді аяқтап, баптауларды өзгерт. Ойынды толық жап, қайта аш: екінші деңгей мен дыбыс баптаулары сақталсын. Unity Remote бұл тесттің орнына жүрмейді.
2. Inspector-да PlayerStats ашып скриншот жаса. Move Speed-ті 4-тен 7-ге өзгертіп, кодты өзгертпей жүрісті көрсет; кейін 4-ке қайтар.
3. JSON мәтінін көрсет. Бұзылған файл сынағын алдымен Editor-де, жеке көшірмеде жаса.
4. Өзіңнің ағылшынша дауысыңмен 2–3 минуттық MP4 түсір. Дайын жоспар: `Docs/Task11_Video_Plan.md`.
